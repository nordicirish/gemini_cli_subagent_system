## Architecture & Runtime
- **Scope:** Local, single-user, human-supervised analytical trading co-pilot bound to loopback `127.0.0.1:8000` (`python/web_server.py` + `python/fetch_stocks.py` FastAPI app + vanilla HTML/CSS/JS in `static/`).
- **Protected Financial Assets (`Protocol 06`, strictly read-only to engineering agents):** `engine_instructions/*.md`, `gem_trading_rules/rules.md`, `context/ssot.json`, `context/trade_lessons.json`, `context/decision_log.json`, `context/config.json`.
- **Entrypoints (`script-mode` safe):** `python/web_server.py`, `python/main.py`, and `python/fetch_stocks.py` all insert `_REPO_ROOT` at `sys.path.insert(1, _REPO_ROOT)` so `python <script>.py` resolves `python.database.*` without `PYTHONPATH` (`tests/test_entrypoints.py`).
- **Persistence:** SQLite + `PersistenceService` (`python/persistence/`, `python/database/`) using `Decimal` contracts (28 total integer+exponent digits via `validate_financial_decimal` and `localcontext()` formatting). Portfolio `shares > 0, wac == 0` returns HTTP 422 (`PersistenceValidationError`), not 503.
- **Market Data Separation:** Live quotes/VWAP run on `MARKET_DATA_COORDINATOR`; historical OHLCV/technicals and options/GEX run on `HEAVY_MARKET_DATA_COORDINATOR`, drained before `coordinate_market_data_cycle()` so spot snapshots match. `calculate_rvol()` emits `row.rvol`; placeholder NO DATA rows have `volume == 0, rvol == 1.0`.
- **Dashboard Frontend:** Pure vanilla JS (`static/portfolio.js`, `static/app.js`, `static/modern_ui.js`) + pinned CDN `marked@15.0.12` and `dompurify/3.2.6` synced with `package.json` (`tests/test_chat_sanitizer.py`, `tests/test_dashboard_scripts.py`). `#data-table` currently has 14 columns including `rVol`.
- **Agent Runtime & Council:** Calls local `agy.exe` (`python/agent_framework.py`) with `MAX_AGY_STDIN_BYTES = 90_000` bounded prompt compaction, `model_name` forwarding (`Hydrogen`, `Neon`, `Argon`, etc.), and SSoT halt-veto guards (`_is_halted_execution_payload`).

- **Test Runner & Tiers:** Python stdlib `unittest` (never introduce `pytest`). Heavy stress suites stay opt-in under `RUN_EXTENDED_TESTS=1`. Keep `test_run_prompt_timeout_triggers_cleanup_and_preserves_exception` classified as *Intermittent Contention / Timing* without weakening it.
