## Architecture & Runtime
- **Scope:** Local, single-user, human-supervised analytical trading co-pilot bound to loopback `127.0.0.1:8000` (`python/web_server.py` + `python/fetch_stocks.py` FastAPI app + vanilla HTML/CSS/JS in `static/`).
- **Protected Financial Assets (`Protocol 06`, strictly read-only to engineering agents):** `engine_instructions/*.md`, `gem_trading_rules/rules.md`, `context/ssot.json`, `context/trade_lessons.json`, `context/decision_log.json`, `context/config.json`. (Consolidated under Class A/B Owner sign-off in `1f7d48c`.)
- **Entrypoints (`script-mode` safe):** `python/web_server.py`, `python/main.py`, and `python/fetch_stocks.py` all insert `_REPO_ROOT` at `sys.path.insert(1, _REPO_ROOT)` so `python <script>.py` resolves `python.database.*` without `PYTHONPATH` (`tests/test_entrypoints.py`).
- **Persistence:** SQLite + `PersistenceService` (`python/persistence/`, `python/database/`) using `Decimal` contracts (28 total integer+exponent digits via `validate_financial_decimal` and `localcontext()` formatting). Portfolio `shares > 0, wac == 0` returns HTTP 422 (`PersistenceValidationError`), not 503.
- **Market Data & Deterministic Quant Engines:** Live quotes/VWAP run on `MARKET_DATA_COORDINATOR`; historical OHLCV/technicals and options/GEX run on `HEAVY_MARKET_DATA_COORDINATOR`. In-process deterministic modules (`analytics_engine.py`, `peak_predictor.py`, `sec_edgar.py`, `macro_calendar.py`, `merton_optimizer.py`, `decision_backtester.py`, `alert_monitor.py`) enrich `/api/data` and `/api/analytics/*` without LLM latency.
- **Dashboard Frontend:** Pure vanilla JS (`static/portfolio.js`, `static/app.js`, `static/modern_ui.js`) + pinned CDN `marked@15.0.12` and `dompurify/3.2.6` synced with `package.json` (`tests/test_chat_sanitizer.py`, `tests/test_dashboard_scripts.py`). `#data-table` has 14 columns including `rVol`. Tools sidebar streamlines Watchlist + Rescan, tabbed `🔭 Discovery` (`Quant Screen (500+)` / `Sector AI`), tabbed `📊 Quant Lab` (`Live Quant` / `Colab MCP Lab` + collapsible Offline Calibration), and slim `⚙️ Admin`.
- **Google Colab MCP Integration (Stages M1–M4, `895e253`–`a99a257`):** Dual-mode `mcp==2.3.0` client (`python/colab_mcp_client.py`: stdio `uvx googlecolab/colab-mcp` & hosted HTTP + offline JSON fallback), single-flight async job runner (`python/colab_jobs.py`), Schema v2.0 validation (`python/colab_calibration.py`), and 4 workers (`vol_surface_greeks.py`, `quant_scout_screener.py`, `sec_nlp_analyzer.py`, `walk_forward_backtester.py`). Zero-secret outbound bundles only; Council consumes signals read-only via `read_colab_quant_signals()`.
- **Agent Runtime & Council:** Calls local `agy.exe` (`python/agent_framework.py`) with `MAX_AGY_STDIN_BYTES = 90_000` bounded prompt compaction, parallel read tool dispatch (`python/agent_factory.py`, `python/tool_dispatcher.py`), and SSoT halt-veto guards (`_is_halted_execution_payload`).

## Decided — Don't Re-Propose
- **Local Security Model:** Loopback `127.0.0.1` + explicit `TRUSTED_LOCAL_ORIGINS` CORS + `allow_credentials=False` + `authorize_financial_mutation()`. Do NOT add session cookies, CSRF middleware, or full auth dependencies for single-user local operation.
- **Test Runner & Tiers:** Python stdlib `unittest` (never introduce `pytest`). Heavy stress suites stay opt-in under `RUN_EXTENDED_TESTS=1`. Keep `test_run_prompt_timeout_triggers_cleanup_and_preserves_exception` classified as *Intermittent Contention / Timing* without weakening it.
- **Role Manifests:** `docs/agents/roles.json` is the single source of truth; `.agents/agents/<role>/agent.md` and `.claude/agents/<role>.md` are generated by `python scripts/sync_agent_manifests.py` — never hand-edit generated manifests.
